# 白昼夢シーン 文章稿 V1 ——「白い椅子」

> 企画書V3 §8 の実装稿。谷崎潤一郎『白昼夢』の核（**麻酔下で愛する対象が美しいまま解体されていく恍惚と恐怖／夢と現実の溶解**）を、本作の設定（水城歯科・笑気ガス・七海・カントリーマアム・セラミックアート）へ落とし込む。
>
> **厳守する原則**
> - 七海は**無垢な被害者のまま**。自発的な裏切り（NTR）は描かない。夢の中でも彼女は微笑み、抵抗せず、ただ削られていく。
> - 猟奇は**「歯」に集約**する。全身を切り刻む描写はしない。白で統一し、血ではなく**セラミックの白**へ収束させる。直接的な性描写は置かず、エロスは「死と美の耽美」「聖性と冒涜の同居」として暗示にとどめる（対象16+）。
> - 視点は**理性 vs 陶酔の摩擦**。INTJの徹が「これは夢だ、記録しろ」と理性で抗うのに、ガスと美に意識を持っていかれる。この葛藤がキャラと谷崎を両立させる。
> - 回を追うごとに**解像度が上がる**（気配 → 手つき → 音と匂い → 痛覚と記憶の汚染）。白昼夢の鮮明さ＝認知侵食メーター。

---

## 反復構造のテンプレ（毎回の検診の“枠”）

白昼夢は独立シーンではなく、**年1回の検診に必ず差し込まれる定型**。毎回ほぼ同じ枠で、中身（白昼夢の解像度）だけが少しずつ変わる。「同じことの繰り返しなのに、何かが違う」という感覚そのものが恐怖になる。

```
① 受付      … セラミックアートが視界に入る（スマホスコープで記録可能）
② 問診      … 水城の慇懃なセリフ。徹をマークするはずが、毎回マークされている
③ 麻酔      … 笑気ガス。視界が白む。音が遠ざかる
④ 白昼夢    … 隣の診察台の七海（※回ごとに変化＝下記）
⑤ 覚醒      … トレイの上の「小さくなったカントリーマアム」と「七海の婚約指輪」
⑥ 選択      … 〔記録する〕／〔忘れる（目を逸らす）〕 → 認知メーターと改変耐性ログに反映
```

> **メカニクス接続**: ④の最中、プレイヤーは〔目を閉じる〕か〔スマホスコープで覗き撮る〕かを選べる。撮れば**改変耐性ログ**（TRUE鍵）になり得るが、正視＝認知への負荷（PARANOIA方向）。撮らなければ翌日「ただの夢」として上書きされる。**真実に近づくほど壊れる**という本作の根幹を、検診のたびに突きつける。

## 第1回（序盤・第1幕）——「気のせい」

### 演出ノート
解像度・最低。白いフラッシュ一閃。何も確定させない。プレイヤーに「今の、何？」とだけ思わせて流す。ここで撮らせない（撮影UIはまだ出さない）。

### 本文

> 「では片瀬さん、すこしだけ眠くなりますよ」
>
> 鼻に当てられたマスクから、ほのかに甘い空気が流れ込んでくる。天井の無影灯が、やけに白い。

徹は壁の時計を見ようとした。秒針の位置を、記録しておこうと思ったのだ。職業病のような癖だった。

だが目盛りに焦点が合う前に、世界の音量が、つまみを回したように下がっていく。

ロータリーの騒音。隣の診察室のドリル。受付の電話。――ぜんぶが、薄い膜の向こうへ遠ざかる。

視界の端、右隣の診察台。

そこに、誰かが寝ているような気がした。

白い。とても白い。逆光で、輪郭がにじんでいる。こちらを向いて、笑っている――気がする。

> （……七海？）

そう思った瞬間、無影灯の白が膨らんで、視界を呑んだ。

― ― ―

> 「はい、おつかれさまでした。よく眠れたみたいですね」

水城の声で、徹は目を覚ました。口の中が痺れている。右隣の診察台には、誰もいない。畳まれた清潔なタオルがあるだけだ。

会計のトレイに、小袋のカントリーマアムが一つ載っていた。サービスです、と受付が微笑む。

> （……こんなに、小さかったか？）

徹はそれを上着のポケットに入れた。指先が、なぜか冷たかった。

**〔この日の白昼夢は記録できない。徹自身が「気のせい」として処理する〕**

## 第5回前後（中盤・第2幕）——「手つき」

### 演出ノート
解像度・中。**水城の“手つき”が見え始める**。だが輪郭はまだ夢の質感（音は遠い、痛覚なし）。トレイの上の白い欠片＝抜かれた歯が、回を追うごとに1つずつ増えている（受付のセラミックアートの増築と同期）。ここで初めて撮影UI〔覗く〕が出る。

### 本文

甘い空気。白い光。今日も、世界の音量が下がっていく。

徹は今日こそ、と思っていた。理性の手綱を、ガスに渡さない。隣の台で何が起きるのか、最後まで見ておく。記録しておく。

右隣。白いシーツ。その上に、七海がいた。

眠っているのか、起きているのか、わからない。睫毛が伏せられ、唇がわずかにほどけている。逆光の中で、彼女の肌は陶器のように白かった。生きているものの白さではなかった。

そばに、水城が立っている。

恭しい手つきだった。芸術家が、壊れやすい作品に触れるときの手つき。彼は七海の唇にそっと指をかけ、押し開く。並んだ歯が、無影灯を受けて光る。

ピンセットのような器具が、奥へ滑り込んでいく。

> **水城**「ね、きれいでしょう」

カチ、という硬い音が、膜の向こうで小さく鳴った。

水城の指先に、白い小さなものがつままれている。歯だ。彼はそれを、傍らのトレイに、宝石のように置いた。

トレイの上には、もう何本も――いつから増えていたのか――同じ白い欠片が並んでいた。

七海は、痛がらない。微笑んだまま、こちらを見て、口を動かす。声は遠くて聞こえない。けれど唇の形で、わかってしまった。

> **七海**（前からこうでしたよ）

> （ちがう）と徹は思う。（前からじゃない。お前の歯は、）

― ― ―

無影灯の白が膨らむ。

> **〔SELECT〕**
> 〔目を閉じる〕 → 翌朝、この検診の記憶は「ただ眠っただけ」に上書きされる
> 〔スマホスコープで覗き撮る〕 → 改変耐性ログ候補に保存。ただし以後、徹の白昼夢は鮮明になる（認知メーター上昇）

覚めると、右隣の台は空だった。会計のトレイに、小さくなったカントリーマアムと――見覚えのある指輪が一つ。

七海の、婚約指輪だった。

> 「お忘れ物ですか？」と受付が首をかしげる。「いえ、最初から、トレイの備品ですけど……前から、ここにありましたよ」

## 終盤（第4幕・時効間近）——「現実と、見分けがつかない」

### 演出ノート
解像度・最大。**音・匂い・痛覚を伴う**。ここでは無影灯の白が「夢の合図」として機能しなくなる――現実の歯科の白と、夢の白の区別がつかない。覚醒後も「夢だった」と言い切れない。七海が初めて、はっきりした声で徹を呼ぶ。残酷さではなく、**美と喪失の純度**で殴る。

### 本文

もう、何度この椅子に座っただろう。

甘い空気。痺れる口。けれど今日は、音が遠ざからなかった。むしろ、近い。器具のぶつかる音。水の流れる音。誰かの息づかい。匂いまでする――消毒液と、ほんの少し、甘い血の匂い。

右隣に、七海がいた。

逆光ではなかった。はっきりと、見えた。十五年前のままの、二十九歳の七海。少し大きめの耳。物憂げな瞳。守りたかった、あの儚さのまま。

彼女がこちらを向いた。今日は、声が聞こえた。

> **七海**「徹さん。やっと、来てくれた」

徹は立ち上がろうとした。腕が動かない。麻酔だ。それとも、これは。

水城が、七海の唇を開く。あの恭しい手つきで。並んだ歯の、左の犬歯。わずかに歪んだ、彼女だけの形。徹が世界でいちばんよく知っている、あの傷。

ピンセットが、それに、かかる。

> **徹**「やめろ……ッ」

カチ。

抜かれた歯の白さが、痛みになって、徹自身の奥歯に走った。自分の口の中で、何かが軋む。鏡を見るまでもなく、わかる。削られているのは、七海だけじゃない。自分も、ずっと、この椅子で。

七海は、最後まで微笑んでいた。痛がらず、責めもせず。ただ、白い指で、自分の薬指に触れた。そこに、指輪はなかった。

> **七海**「ね。きれいでしょう」

それは、水城の声と、同じ言葉だった。

― ― ―

目を覚ます。

天井の白。口の中の痺れ。右隣の診察台――には、

> **〔分岐〕**
> ・ここまで白昼夢を記録してこなかった → 台は空。「また、夢か」。だが今日は、夢だと思えなかった。〔BAD方向〕
> ・記録を重ねてきた → 台は空。だがシーツに、抜けた髪が一本。徹はそれを、震える指で違和感ログに収める。〔TRUEへの最後の改変耐性ログ〕
> ・「現実だ」と確信して水城に掴みかかる → 〔パトカーエンドへ〕

会計のトレイ。小さくなったカントリーマアム。婚約指輪。

徹はもう、それが「前からあった」のか「今日あらわれた」のか、思い出せない。

## TRUE接続——「夢では、なかった」

終盤、徹が最後のセルフィー写真を極限まで拡大し、七海の**歪んだ犬歯の傷**を視認したとき。受付のセラミックアートを割り、その中の一本と照合したとき。

形が、完全に一致する。

そして徹は思い出す。あの白昼夢で、水城のピンセットが最後にかけた歯。左の犬歯。歪んだ傷。

> **「ただの夢」だと思って、目を閉じた日々がある。記録しなかった日々がある。**
> **だが、夢は最初から、現実の“予習”だった。** 水城は徹の認知の中で、これから自分がやること（あるいは、もうやったこと）を、麻酔という名の自白として、毎回見せていたのだ。

最も鮮明に「見て」しまった者だけが、最後にこの一致へ辿り着ける。**白昼夢を記録した本数 ＝ TRUE到達のゲージ**として、ここで回収する。

## 演出・実装ノート

| 要素 | 仕様 |
|------|------|
| **VFX** | 笑気ガス導入時、画面周縁が白くにじみ、被写界深度が浅くなる。彩度を上げ、無影灯のブルームを強調。回が進むほど「白み」のかかりが速く・深くなる（認知メーターと連動） |
| **SE** | 序盤＝環境音にローパスをかけ遠ざける（夢の合図）。終盤＝**あえてローパスを外す**（現実音が侵入＝夢と現実の区別の消失）。「カチ」という歯の硬質音を全回共通のモチーフ音に |
| **七海の顔（i2i）** | 回を追うごとに、歯だけが過剰にホワイトニングされ、輪郭がわずかに“水城好み”へ補正されていく。だが**表情は無垢なまま**（人格は侵さない＝被害者性の保持） |
| **撮影UI** | 白昼夢中の〔覗き撮る〕は成功率が低く、手ブレ演出が入る。撮れた写真は他ログと違い改変耐性を持つが、所持しているだけで認知メーターが上がる（正視の代償） |
| **トレイ演出** | カントリーマアムは回ごとに実測で数px小さくなる。婚約指輪は「備品」テキストに上書きされていくが、記録済みプレイヤーの画面でだけ“指輪”表記が残る |
| **分岐フラグ** | 白昼夢の累計記録数で BAD / NORMAL / TRUE のゲージが分岐。終盤の「掴みかかる」選択のみ即パトカーエンド |
