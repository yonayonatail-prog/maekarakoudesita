# 『前からこうでした』完全企画書

**英題**: It's Always Been This Way.

---

## 1. 企画概要

| 項目 | 内容 |
|------|------|
| **ジャンル** | 認知侵食型・都市生活ホラーアドベンチャー（心理サスペンス / マルチエンディング） |
| **プラットフォーム** | PC（WebGL） / Steam / itch.io |
| **プレイ時間** | 1周：2〜4時間 / 全ルート回収：8〜12時間 |
| **対象年齢** | 16歳以上（サイコサスペンス） |
| **参考原作** | 谷崎潤一郎『白昼夢』（認知と狂気の境界線） |

**核心テーマ**

> 「人間は、ゆっくり変化したものを正常として受け入れてしまう。」

世界は少しずつ削られていく。商品のサイズ。景色。記憶。人間関係。人生。そして、自分自身。

プレイヤーはその違和感を記録しながら、連続殺人事件の真相を追う。

しかし調査が進むにつれ、指名手配犯の似顔絵は徐々に主人公自身へ近づいていく。

## 2. ストーリー

### オープニング（プロローグ）

同棲中のアパートのベランダ。ペアマグカップ。結婚式場のパンフレット。

29歳の主人公・徹と、恋人・七海が穏やかな朝を過ごしている。

**主人公**「カントリーマアムってこんなに小さかったっけ？」

**七海**「前からこうでした。」（あの聖女のような笑顔で）

二人がベランダからインカメのセルフィーを撮る。背景には、駅前で有名な歯医者の巨大広告看板が映り込む。

それが、最後の写真だった。

### 事件

ある日、街で殺人事件が起きる。被害者は七海。

ニュースでは犯人の似顔絵が連日報道されるが、犯人は一向に捕まらない。

警察も、世間も、誰もが犯人を追う。

しかし、徹だけが違う観点に気づく。

### 違和感の発見

駅前の歯医者広告。院長の顔が、少しずつ変わっている。

3ヶ月ごとに背景色が変わり、それと同時に院長のパーツが微妙にすり替わっていた。

これは「まさに事件を犯す前から始まっていた」という衝撃の事実。

看板は「毎日なんとなく見ているもの」だからこそ、1%ずつの変化に人間は気づかない。

徹は、最初のツーショット写真と、現在の看板の顔を定規で測り、寸法をとり始める。

やがて徹は、街そのもの全体が「微細な変化による上書き」を受けていることに気づき始める。

### 物語の転機：タイムリープ

現代（事件から3ヶ月後）で看板の異変に気づいた徹は、水城歯科の受付でカントリーマアムをもらう。

そのお菓子の「賞味期限が今日」である。

それを食べた瞬間、味が「1年前の大きなサイズ」へ逆流し、徹は七海が殺される1年前へタイムリープする。

ここから本編が始まる。

## 3. ゲームシステム

### 時間進行：「一晩寝るごとに1年進む」

**基本ルール**
- プレイヤーは1年前の時点からスタート
- 毎晩、アパートで寝ると1年が経過
- 全15回寝ると時効成立（15年）
- 現在の主人公は41歳になっている

**1年周期の意図**
- 年次定期検診のタイミングと一致（年1回）
- 1年単位の時間飛躍が「削られる感覚」を強調
- プレイヤーの「時間が削られる感覚」を最大化

### 違和感ログ：記録するか、忘れるか

**仕様**
- スマホアプリ「違和感ログ」に発見した違和感を記録
- 写真撮影、メモ、比較機能を搭載
- タイムスタンプ付きで「あの事件から◯日目」と保存される

**恐怖メカニクス**
- 記録しなかった違和感は翌日「正常」として上書きされる
- 過去写真のデータも改変される（プレイヤー自身が観測していない変化は記憶も書き換わる）
- カメラロール内の画像すら、徐々に変化する
- 「何が真実で、何が幻か」がわからなくなる

### スマホスコープ：寸法をとる

**操作**
- 街のオブジェクトをタップするとカメラ起動
- スワイプでスコープ（ズーム・画角）を調整
- グリッド線を当てて「寸法を測る」

**演出の意図**
- ロゴの「前」の文字の2本の縦線はこの「定規」を象徴
- 「測らないと小さくなったか分からない」という狂気的なデジタル解析がプレイの触感になる
- プレイヤー自身が執着の虜になっていく

### 年次定期検診イベント

**仕様**
- 新しいステージが始まる初日、スマホに【水城歯科・定期検診 14:00〜】の通知
- 徹は水城を「マーク」するために通院するが、実は毎回少しずつ顔の骨格を削られている
- 定期検診のたびに「あの白いセラミックアート」にパーツが増築されていく

## 5. セラミックアート：核心的ギミック

### 真実

歯科医院の受付に飾られている「白く美しいセラミック彫刻」は、水城が七海の遺体から抜き取った「歯」を素材に作った芸術作品。

### 演出

**15年間のループ中**
- 徹は定期検診のたびに受付に座る
- その前の「白い彫像」を毎回見つめている（違和感ログに記録できる）
- 実は、徹の治療で削られた歯も、パーツとして埋め込まれている

**視覚的進行**
- 回を重ねるごとに、パーツが増築されていく
- 「あの白い美しいオブジェが、実は人間の歯でできている」という恐怖
- 水城は「トロフィー」として、白日の下に置き続ける

### TRUE END への鍵

最後のインカメ写真（29歳のベランダでのツーショット）に写っている七海の歯。

「わずかに形が歪んでいる、七海特有の犬歯の傷」という固有のパーツは、この写真の中にだけ100%の解像度で遺されている。

時効寸前、徹はこの歯の形状と、受付のセラミックアートの1本を照合し、完全一致させることで、15年間の世界全体のハッキングをひっくり返す。

## 6. マルチエンディング

### 🚨 パトカーエンド（BAD/トラップルート）

**条件**
- タイムリープ中に「七海を部屋に監禁して外に出さない」を選択
- または「水城歯科に殴り込みで凸」

**展開**
1. 七海を絶対に外に出さず、一晩寝る
2. 起きるといない→ニュースで「交際男性が同棲アパートで交際女性を監禁殺害」と報道
3. パニックになった徹が水城歯科へ凸：「お前だ！」
4. 水城は美しい笑顔で通報
5. パトカー連行される徹の窓から、水城の顔が「警察官の認知の中で徹の顔へ」すり替わっていく

**プレイヤーへの効果**
- 「力ずくで運命を変えられない」ことを叩きつける
- 真正面から抗っても、世界（社会システム）に排除される
- 次のプレイでは「潜伏」という選択へシフト

### 🦷 白昼夢ルート（NTR/パラノイア）

**条件**
- 定期検診を何度も受ける
- ベランダからスマホスコープでクリニック2階を覗く

**展開**
1. 治療台の上で、水城に恍惚の表情で抱かれる七海を目撃
2. 問い詰めても、七海は無邪気に笑う：「前からこうだよ？ 先生のおかげで歯が綺麗になったの」
3. 彼女の歯は過剰にホワイトニングされた「水城好みの人工的な白い歯」に変えられている
4. 孤立した徹が白昼、誰もいない診察室に踏み込む
5. トレイの上には「小さくなったカントリーマアム」と「七海の婚約指輪」だけ
6. パトカーのサイレンが聞こえる

**恐怖の本質**
- 谷崎『白昼夢』のドロドロしたエロティシズムと猟奇性
- 自分が見たもの（浮気）が幻なのか、現実なのか不明
- むしろ「浮気」ではなく「素材化」という最悪の可能性

### 💾 NORMAL END（平行世界エンド）

**条件**
- 中程度の違和感を記録
- 一部ルートをクリアしたが、決定的な証拠は集められず

**展開**
- 犯人逮捕（？）
- しかし数年後、新たな連続殺人事件が発生
- テレビの似顔絵は「少しだけ別の人に似ている」
- システムは次のターゲットへ移行している

### 📌 BAD END（完全同化）

**条件**
- 違和感を見逃し続ける
- 記録を怠った

**展開**
- 徹は世界へ完全に同化する
- テレビを見ながら、自分の顔が映ったニュースに「怖いですねえ、この犯人」と呟く
- 本人の認知もセーブデータも上書きされて終了

### 👁️ PARANOIA END（ゲシュタルト崩壊）

**条件**
- 観察しすぎた
- ログを見返しすぎた

**展開**
- 世界のあらゆるものが「変化している」ように見える
- 月のサイズ。道路。人間の身長。空の色。すべてが削られている
- 最後、鏡の中の自分を見て：「……誰？」
- プレイヤーの脳も認知侵食を受けたエンド

### ✨ TRUE END（指紋による真実）

**条件**
-　TRUE条件の違和感を記録
- セラミックアートを何度も観察
- 最後のインカメ写真を拡大分析

**展開**
1. 時効寸前、徹はアパートのベランダで最後のツーショット写真を極限まで拡大
2. 七海の「わずかに歪んだ犬歯」のパーツが完全に視認される
3. 警察を連れて水城歯科へ凸
4. 受付のセラミックアートを叩き割り、その中の1本を確保
5. 歯の形状データが完全一致、DNA・指紋も完全一致
6. 「顔はいくら書き換えられても、指紋と骨だけは隠せない」

**エンディング**
- 水城は逮捕される
- しかし、43歳になった徹には「15年の人生」が戻らない
- ベランダから、かつての看板が真っ白な状態に。

## 7. ビジュアル設計

### タイトルロゴ

**構成**
- **基本形**：逆三角形（上が重く、下が尖った不安定な形）
- **「前」の「月」部分**：明朝体で、左側のハネを強調
- **他の文字「からこうでした」**：「みなさんのおかげでした」風の詰まった組み字

**配置**
- 「前」の2本の縦線（測定用の定規）が、中央のカントリーマアムを左右から挟む
- 全体が逆三角形にすぼむことで、世界の縮小感を表現
- 黒背景に白抜き、あるいは黄色・赤の派手な背景への配置も想定

**心理的効果**
- ロゴ自体が「違和感」を放つ
- 「月だけが異質」というパーツのすり替えを視覚化
- 定規の2本線は、プレイヤーが何度もスマホで測定する行為を象徴

### アートスタイル

**方針**: 「セミリアル × 地方広告感」

**キーワード**
- 歯医者チラシ
- 不動産広告
- 学習塾ポスター
- 結婚式場パンフ
- HDR写真の過補正感
- AI補正による不自然な清潔感
- 過剰なホワイトニング

**背景とテクスチャ**
- 実写寄りだが、どこか「人工的」な空気感
- 色彩が飽和し、原色（黄色・赤・黒）が目に付く
- ローポリとリアルの間を狙う

### 顔変化演出

**技術手法**: AI Image-to-Image による微分生成

**特徴**
- 完全な別人ではなく、「気のせいレベル」の変化
- 微細な輪郭の差分
- 歯列の変化
- 笑顔角度の微調整
- 肌質感の更新

**演出**
- 「観測していない間に変化する」
- 車が横切った後に看板が変わる
- 瞬き後に写真が変化
- スマホをリロードしたら顔が更新されている
- スマホの自動補正で顔が勝手に綺麗になる

### 世界全体のコストカット

ゲームが進むほど、都市そのものが「削られていく」：

- 建物密度の減少
- コンビニの商品数減少
- 通行人の減少
- BGM が簡略化（楽器が減っていく）
- テクスチャの劣化（3Dが背景ベタ貼りに置き換わる）
- 洗濯物が減る
- マグカップが1個消える

プレイヤーは「何が減ったのか」を正確に説明できない。しかし、確実に何かが失われている。

- 街のオブジェクトをタップ → カメラ起動

- 「測らないと小さくなったか分からない」という狂気的デジタル解析がプレイ手触りに

### 違和感ログ

- スマホアプリとして機能
- 撮影、メモ、比較記録
- タイムスタンプ：「あの事件から◯日目、水城歯科大看板」
- **恐怖**: 記録しなかった違和感は翌日「正常」として上書きされる
- **さらに恐怖**: 過去写真のデータまで改変される

## 9. テーマと現代社会への関連

### シュリンクフレーション（ステルス値上げ）

- 商品のサイズが小さくなっているのに気づかない
- 値段は同じなのに、内容量が減っている
- これを気づく人は少ない、気づかない人がほとんど

→ このゲームは「シュリンク」を「認知改変」にアップグレードしている

### AI時代の平均化

本作は「AIが暴走する話」ではない。むしろ：

> 「人間側が、AI的最適化へ順応していく恐怖」

- 顔補正
- 広告最適化
- SNS平均化
- 記録補完
- ノイズ除去

その積み重ねによって、人間の認知そのものが削られていく。

### 広告社会への不安

派手な色彩（黄色・赤・黒）の歯科看板。街を埋め尽くす広告。

その中に、最大の秘密が隠されている。

視覚的・心理的なパラドックス：「最も目立つ場所に、最大の嘘がある」

- 「それが最後の写真だった。」

## 13. 最終まとめ

### 『前からこうでした』とは

これは「異変を見つけるゲーム」ではない。

それは：

> 「自分の認知を、どこまで守れるか」を問うゲーム

現代社会の違和感。AI時代の平均化。シュリンクフレーション。広告。SNS。

その全てを「静かな恐怖」へ変換する認知侵食ホラー。

プレイヤーは主人公と一体化し、15年間のベランダでの執着を体験する。

そして、もしかしたら自分も「すり替わっている」かもしれない。

その疑念を、プレイ後もずっと引きずり続けることになる。
