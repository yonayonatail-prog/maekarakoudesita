# 『前からこうでした』企画書

**英題**: It's Always Been This Way.

---

## 0. 一言で表す、絶対的な強み（ログライン）

> ### 「あなたの大切なものは、盗まれたんじゃない。少しずつ小さくされて、消えた。」

- **サブログライン**: 「“前からこうでしたよ”——記憶が毎晩上書きされる15年。違和感を測り続けた者だけが、消された恋人がいた証拠を残せる。」
- **一言ジャンル(造語)**: **シュリンクフレーション・ホラー**（ステルス値上げの“あるある”を、喪失の恐怖へ反転させる）

### なぜこれが「誰にも真似できない核」なのか

本作の全モチーフは、偶然ではなく**必然で一本に連鎖している**。

```
カントリーマアムが小さくなる（縮む）
   → 歯で噛む菓子
      → 歯医者の巨大看板
         → 七海の歯を抜く（犯行）
            → 抜いた歯のセラミックアート（トロフィー）
               → 犬歯の傷で真実を照合（解決）
```

**「歯」と「縮む」が、テーマ・ミステリ・ギミック・泣き所のすべてを貫く。** これが本作の背骨であり、企画の発明点である。「世界が少しずつ小さくなっている」という誰もが薄々感じる不安を、**「愛する人がこの世界から1%ずつ削り取られて消えた」という喪失のメタファー**に接続することが、本作の唯一にして最大の狙いである。

## 2. テーマ

> ### 「人間は、ゆっくり変化したものを正常として受け入れてしまう。」

世界は少しずつ削られていく。商品のサイズ。景色。記憶。人間関係。人生。そして、自分自身。

プレイヤーはその違和感を記録しながら、恋人を奪った連続殺人の真相を追う。
しかし調査が進むにつれ、指名手配犯の似顔絵は、徐々に主人公自身へ近づいていく。

**幹（ハイブリッド）の宣言**:
本作は「解ける話」であり「救われない話」である。犯人は実在し、論理で必ず特定できる。だが真実に到達しても、削られた15年も、消えた七海も戻らない。**プレイヤーは知的カタルシス（謎解きの勝利）と感情的喪失（戻らない）を同時に浴びる。** この二層こそ本作の体験設計の核である。

## 3. ストーリー

### プロローグ（正常な日常）— 令和元年・夏

同棲アパートのベランダ。ペアマグカップ。結婚式場のパンフレット。干された洗濯物。
26歳の主人公・**片瀬徹**と、幼馴染で恋人の**七海**が、穏やかな朝を過ごしている。

> **徹**「カントリーマアムって、こんなに小さかったっけ？」
>
> **七海**「前からこうだったよ？笑　私たちが大きくなったんだよきっと」

二人はベランダでセルフィーを撮る。背景には、駅前で有名な水城歯科の巨大広告看板——院長の、不自然なほど左右対称の白い笑顔。

**それが、この世界で二人が過ごした「最後」の、そして「正常」な日常の記録だった。**

### 事件

直後、街で連続殺人事件が起きる。被害者の一人が、七海。
ニュースは犯人の似顔絵を連日報道するが、犯人は一向に捕まらない。世間は「遺体の一部が損傷」としか知らない。

### 違和感の発見（現代＝事件から3ヶ月後）

徹だけが、別の観点に気づく。駅前の水城歯科の看板。**院長の顔が、少しずつ変わっている。**
背景色は3ヶ月ごとに変わり、それと同期して院長のパーツが微妙にすり替わっていた。看板は「毎日なんとなく見ているもの」だからこそ、1%ずつの変化に誰も気づかない。
徹は、最後のツーショット写真と現在の看板を定規で測り、寸法を取り始める。やがて、街そのものが「微細な変化による上書き」を受けていることに気づく。

### 転機：認知タイムリープ

異変に確信を持った徹は、水城歯科の受付で、賞味期限が今日のカントリーマアムをもらう。
それを口にした瞬間、味が「1年前の、大きかったサイズ」へ逆流する。**徹の“認知”だけが、七海が殺される1年前へ巻き戻る。**（→ §4）
ここから本編が始まる。

### 本編 → 真実（TrueEnd）

徹は1年前をやり直す。だが何度記録を重ねても、七海の死という物理的事実は変えられない。徹にできるのは、世界が改変しきる前に違和感を**測り、記録し続ける**ことだけ。
15年の果て、時効寸前。徹は最後のツーショット写真を極限まで拡大し、七海の**わずかに歪んだ犬歯の傷**を視認する。受付のセラミックアートを割り、その中の1本と照合——完全一致。「顔はいくら書き換えても、骨と歯と指紋だけは隠せない」。
水城は逮捕される。しかし、41歳になった徹に、15年も七海も戻らない。

## 4. 時間構造：認知タイムリープ

### 「物理移動」ではなく「認知の巻き戻し」

- カントリーマアムの**賞味期限間際の個体**は、世界改変が及ぶ前の「1年前の味（大きさ）」を保持した最後の1個。
- それを食べると、**味覚＝感覚記憶が1年前に同期**し、徹の**認知だけ**が過去へ巻き戻る。体も世界も“現在”のまま。
- だから——**世界の改変は止められない。七海の死も覆せない。** やり直せるのは「観測」と「記録」だけ。
- これがハイブリッドの幹を支える: **「救えないが、真実には届く」**。

### 進行ルール

- 本編は1年前の時点からスタート。
- アパートで**一晩寝るごとに1年が経過**（＝年次定期検診のタイミング）。
- **時効成立まで全15晩（＝15年）**。ゲームプレイ中の徹は26〜40歳、エピローグで41歳。
- ループは”やり直し”ではなく”喪失の反復”として設計する。何度も七海に会えてしまうが、何度も失う。

## 5. 幕構成と「各幕の主疑惑」

旧版で混線していた「主人公は何を疑っているのか」を、**幕ごとに1つへ固定**する。

| 幕 | フェーズ | 主疑惑（この幕でプレイヤーが疑う対象） |
|----|---------|----------------------------------------|
| **第1幕** | 違和感 | **「自分の記憶がおかしいのでは？」**（自己不信。シュリンク探索のチュートリアル兼“比較する癖”の植え付け） |
| **第2幕** | 認知侵食 | **「世界の方がおかしい。何かに上書きされている」**（世界不信。記録すら改変される絶望） |
| **第3幕** | 比較と証拠 | **「水城が黒幕だ」**（特定。Street View・卒アル・看板の外部記録で外堀を埋める） |
| **第4幕** | 真実 | **「自分が犯人に仕立てられ、自分自身も改変されている」**（自己崩壊と反転）→ TRUEで“犬歯”という物理事実が反転を覆す |

> **似顔絵フックの理屈づけ（旧版の穴を修正）**: 指名手配犯が主人公に似てくるのは、第4幕の「自己改変」の現れ。水城の改変は“最も目立つ場所(看板・ニュース)に最大の嘘を置く”原理で動き、徹を「次の正常」として上書きしようとする。だが**骨と歯だけは改変できない**——ここがTRUEの突破口になる。

## 6. 泣き所の設計

**核となる仕掛け**: シュリンク（縮小）を、徹底して**喪失と同義**に演出する。頭で考えさせず、1枚の絵に落とす。

1. **タイムリープ＝もう会えない人にもう一度会える“地獄”**
   再会の幸福を厚く描くほど、失う痛みが重くなる。タイムリープは便利なやり直しではなく、
   **「何度でも会えて、何度でも失う」反復装置**として設計する。ここが最大の泣き所。

2. **生活から七海が“1個ずつ”消える**
   マグカップ 2→1、歯ブラシ 2→1、茶碗、スリッパ、洗濯物が減っていく。プレイヤーは理由を言葉にできないが、確実に何かが減っている。

3. **クライマックス：街からカントリーマアムが完全に消える**
   徹だけが「昔はもっと大きかった」と言い張る。それは喪失を認めない男の祈り。
   > **「“小さくなった”と言い続けることだけが、彼女がいた証明だった。」**
   ラスト、片方だけのペアマグカップを持ってベランダに立つ徹。看板は真っ白。
   > 「……やっぱり、小さくなってたんだ。お前がいない世界は、全部。」

4. **改変耐性ログ＝“想い”だけが真実を保存する**
   「一部のログだけが改変に耐える」その正体を、**強い愛情を込めて記録した違和感**とする。理屈（システム）ではなく想い（愛）だけが上書きに耐え、TRUE到達の鍵になる。テーマと直結。

5. **「測る」狂気 → 「愛の証明」への反転**
   偏執的な測定行為が、終盤「喪失を認めない祈りだった」と判明する。狂気のゲームメカニクスが、最後に愛の行為へ反転する。

## 7. 笑いどころの設計

ホラーに笑いは必須（緊張緩和・トーン管理・実況映え）。**全原則は「笑った要素が、後で全部こわくなる」二重構造**。

1. **共感の笑い（最大の武器）**: シュリンクフレーション“あるある”。お菓子・トイレットペーパー・ポテチの上げ底。**プレイヤーが現実で確かめたくなる笑い**。実況で必ずウケる。
2. **滑稽と悲劇の同居**: 定規でお菓子を測る徹。周囲から見れば完全に不審者。主観（切実）と客観（ヤバい人）のギャップ。
3. **ブラックユーモア**: 水城院長の慇懃無礼な爽やかさ。「お気持ちはよくわかりますよ、片瀬さん」。
4. **地方広告のダサさ**: きぬた歯科パロディ。「**令和最新版の笑顔へ**」「新時代の白さ」。一見ギャグ、よく見ると不穏（“新時代”＝人間性が削られる起点）。
5. **「前からこうでしたよ笑」の二重性**: 七海の聖女スマイル。序盤は微笑ましく、終盤は世界改変の象徴へ反転。

## 8. 白昼夢演出（谷崎オマージュ）の設計

> 旧『白昼夢ルート』を**廃止**し、**全編に挿入する“認知侵食の演出装置”へ転用**する。

### 原理（谷崎『白昼夢』の核だけを抽出）

谷崎の核は「NTR」ではなく、**(1) 愛する対象が美しいまま解体されていく恍惚と恐怖 / (2) 夢と現実の境界が溶ける**——この2点。七海は**無垢な被害者のまま**でよい。

### 配置：定期検診の麻酔椅子

- 年1回の検診で、水城に麻酔（笑気ガス）を打たれ、意識が溶ける（＝谷崎の舞台そのもの）。
- 朦朧の中、隣の診察台で七海が**美しいまま解体されていく**（歯を一本ずつ抜かれ、それがセラミックへ変わる）幻視を見る。エロスは「死と美の耽美」へ昇華し、**裏切りではなく喪失**として機能する。
- 覚めると診察台には誰もいない。**「夢だった」**。だがトレイには、小さくなったカントリーマアムと、七海の婚約指輪だけ。

### 二重の機能

| 機能 | 内容 |
|------|------|
| **認知崩壊メーター** | 白昼夢の解像度＝徹の認知侵食度。検診のたびに鮮明に・現実に近い質感になる |
| **TRUE伏線** | 「ただの悪夢」と思い記録しなかった解体の幻視は、終盤、**水城が実際に七海の歯を抜きアートにした物理事実**だったと判明。「夢だと思った猟奇が、最初から現実だった」 |
| **分岐への接続** | 白昼夢を**現実と誤認して水城に凸**→ §13「パトカーエンド」へ吸収 |

### 段階設計（例）

| 検診回 | 白昼夢の質感 |
|--------|--------------|
| 1回目 | 一瞬の白いフラッシュ。「七海が笑っていた気がする」程度 |
| 中盤 | 解体の手つきが見え始める。が、輪郭はまだ夢 |
| 終盤 | 音・匂い・痛覚を伴い、現実と見分けがつかない。覚めた後も“夢だった”と言い切れない |

## 10. キャラクター

### 片瀬徹（主人公）/ 26歳 → 41歳
- **MBTI**: INTJ。システムエンジニア。完璧なロジック思考。
- 七海を失い、世界の微細なシュリンクに異常に敏感になる。執着的に測定・記録する。
- **見た目**: 26歳。鏡を見るたび老けていく（26歳のシャープさ → 41歳の白髪・皺・やつれ）。
- **心理軌跡**: 第1幕＝自分の記憶を疑う → 第2幕＝世界を疑う → 第3幕＝水城を疑う → 第4幕＝自分が犯人にされる恐怖 → TRUEで“骨と歯”により反転を覆す。

### 鈴代　七海（ヒロイン）/ 26歳 — **無垢な被害者として一貫**
- **MBTI**: ISFP。徹の幼馴染で恋人。感覚的で「今この瞬間」を無邪気に楽しむ。
- ローポリ3Dモデル（制作済み）。浮世離れした人形のような質感、少し大きめの耳、物憂げで無垢な瞳、守りたくなる儚さ。

### 水城院長（真犯人）/ 30代後半
- **MBTI**: ENFJ。表向きは街全員に愛される完璧な聖職者。圧倒的カリスマと不自然に美しい笑顔。
- 徹の心理を読み、精神攻撃を行う。自分の犯行に「芸術的悦び」を感じるサイコパス。
- **恐怖の本質**: 顔は整形・看板でいくらでも書き換えられるが、**骨（歯）と指紋は残る**。自分の傑作（七海）を受付に飾り、愛おしげに観賞する。
- **象徴的セリフ**:
  > 「お気持ちはよくわかりますよ、片瀬さん。でも、あんまり騒がれると……私も困ってしまいます。本当に残念です。あの美しい彼女の歯が、抜き取られてしまっているなんて……」

## 11. ゲームシステム

### コアループ
```
探索 → 違和感を発見 → スマホスコープで測る → 撮影・記録（違和感ログ）
   → 帰宅・就寝（1年経過）→ 翌朝、記録しなかった違和感は”正常”に上書き
      → ニュース更新／看板すり替え → 次の探索へ
```

### 違和感ログ（スマホアプリ）
- 写真・メモ・比較記録。タイムスタンプ「あの事件から◯日目」。
- **記録しなかった違和感は翌日“正常”として上書きされる。**
- **さらに恐怖**: スクショ・過去写真・メモ・UIまで改変される。記録媒体すら信用できない。
- **救い（＝TRUE鍵）**: 強い想いを込めた記録（改変耐性ログ）だけが上書きに耐える（§6-4）。

### スマホスコープ（測る）
- オブジェクトをタップ→カメラ起動。スワイプでズーム・画角。グリッドで寸法を測定・撮影。
- 「測らないと小さくなったか分からない」狂気的デジタル解析が、プレイの手触りになる。
- ロゴ「前」の2本の縦線は、この“定規”の象徴。

### 定期検診イベント
- 新ステージ初日にスマホへ【水城歯科・定期検診 14:00〜】通知。
- 徹は水城をマークするため通院するが、毎回少しずつ顔の骨格を削られている。検診のたびにセラミックアートにパーツが増築され、麻酔椅子で白昼夢を見る（§8）。

## 12. セラミックアート：核心ギミック

- 受付の「白く美しいセラミック彫刻」は、水城が七海の遺体から抜いた歯を素材にした作品。
- 15年のループ中、徹は検診のたびに受付でそれを見つめる（記録できる）。実は徹の治療で削られた歯もパーツとして埋め込まれていく。
- 回を重ねるごとにパーツが増築。「あの白く美しいオブジェが、人間の歯でできている」恐怖。
- **TRUE鍵**: 最後のセルフィー写真に100%の解像度で遺された七海の犬歯の傷を、セラミックの1本と照合・完全一致させ、15年分の世界改変をひっくり返す。

## 13. マルチエンディング（5＋αに整理）

> **設計思想**: 「観察しなさすぎ(BAD)」と「観察しすぎ(PARANOIA)」の**両端が破滅**。その間の細い道だけがTRUE。これは記録する/しないというコア操作と、「認知をどこまで守れるか」というテーマに直結する。

### ✨ TRUE END — 勝利の中の喪失（幹）
- **条件**: ほぼ全ての違和感を記録／セラミックを反復観察／最後の写真を拡大分析。
- **展開**: 犬歯の照合で水城を逮捕（解決・知的カタルシス）。しかし15年も七海も戻らない（喪失）。片方だけのマグカップ、真っ白な看板、「お前がいない世界は、全部、小さくなってた」。

### 👁️ PARANOIA END — 観察しすぎの崩壊
- **条件**: 過剰観察・ログ見返し過多。
- **展開**: 月・道路・人の身長・空の色、すべてが変化して見える。最後、鏡の中の自分に「……誰？」。

### 📌 BAD END — 観察しなさすぎの同化
- **条件**: 違和感を見逃し続け、記録を怠る。
- **展開**: 徹は世界へ完全同化。ニュースに映る犯人（自分の顔）を見て「怖いですねえ、この犯人」と呟く。本人の認知もセーブデータも上書きされて終了。

### 💾 NORMAL END — 取り逃がし
- **条件**: 中程度の記録。TRUE条件には届かず。
- **展開**: 証拠が弱く誰も信じない（背景ボケ・圧縮・AI補正・主観的違和感）。犯人逮捕(？)の数年後、新たな連続殺人。似顔絵は「少しだけ別の誰か」に。システムは次の標的へ移行。

### 🚨 パトカーエンド — 力ずくの失敗（サブ／白昼夢誤認凸を吸収）
- **条件**: 七海を監禁して外に出さない／白昼夢を現実と誤認して水城歯科へ凸。
- **展開**: 真正面から抗うと社会システムに排除される。連行される徹の窓から、水城の顔が「警官の認知の中で徹の顔」へすり替わる。→ プレイヤーは「潜伏」へ学習する。

  PARANOIA条件 = タイムリープ過多による認知崩壊

  NORMAL条件  = 中程度の記録・証拠不十分
  パトカー条件 = 力ずくの行動・白昼夢の誤認
