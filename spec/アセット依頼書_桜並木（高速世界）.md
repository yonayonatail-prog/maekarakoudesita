# アセット依頼書：桜並木（高速世界・季節サイクル演出）
**対象: 3Dアーティスト**  
プロジェクト: 『前からこうでした』

---

## 0. このアセットの役割

高速世界エリアに配置する桜並木。1本〜複数本を並べて使用する。

この木は **365日分の季節変化を高速ループで繰り返す演出オブジェクト**。  
difF（撮影メカニクス）の対象ではなく、「ここは時間の流れが速い場所」をプレイヤーに直感的に伝えるための**環境演出**として機能する。

---

## 1. 必要なメッシュ

### 1-A. 幹・枝メッシュ（静的）

| 項目 | 仕様 |
|------|------|
| ポリゴン数 | 〜3,000tri（幹1本分） |
| UV | UV1展開済み（ライトマップ用） |
| マテリアル | 1マテリアル（樹皮テクスチャ） |
| 原点 | 根元中央に配置 |
| 備考 | **葉なし状態**（枯れ木として単体でも成立すること） |

### 1-B. 葉メッシュ（季節カラーアニメーション対象）

| 項目 | 仕様 |
|------|------|
| ポリゴン数 | 〜2,000tri（木1本分） |
| UV | UV1展開済み |
| マテリアル | 1マテリアル・**vertexColorあり**（色をコード側で制御するため） |
| 形状 | 枝全体を覆うボリューム感のある葉の塊（LOD不要） |
| 原点 | 幹と同じ根元中央 |
| 備考 | 桜の花・紅葉・新緑、すべて**同一メッシュ**で対応。色・不透明度はコード制御。 |

> **重要**: テクスチャに季節の色を焼かないこと。葉メッシュはベース色を白〜薄グレーで納品。コード側でHSLアニメーションを適用します。

## 3. フェーズイメージ（参考）

コード側は以下の6フェーズを補間します。アーティストは「枯れ木」と「葉のシルエット」が成立していれば色は参考程度でOKです。

| フェーズ | 雰囲気 | 葉の色 | 葉の密度 | パーティクル |
|---------|--------|--------|---------|------------|
| 桜 | 春・満開 | ピンク（#ffb7c5） | 100% | 花びら |
| 新緑 | 初夏 | 明るい黄緑（#b5e853） | 100% | なし |
| 深緑 | 真夏 | 濃い緑（#2d6a2d） | 100% | なし |
| 紅葉 | 秋・最盛期 | 赤〜黄（#cc4400） | 100% | なし |
| 葉が落ちる | 晩秋 | くすんだ赤（#884400） | 10%まで減少 | 枯れ葉 |
| 枯れ木に雪 | 冬 | ―（葉なし） | 0% | 雪 |

## 4. 納品仕様

| 項目 | 仕様 |
|------|------|
| ファイル形式 | GLB（幹・葉それぞれ個別ファイル） |

| スプライト | `particle_sakura_0.png` / `particle_leaf_0.png` / `particle_snow.png` |

---

## 5. 注意事項

- **葉メッシュは1枚の統合メッシュ**で納品（葉を1枚ずつモデリング不要）
- アニメーションデータは不要。動きはすべてコード制御
- 幹メッシュは**葉なし・季節問わず成立するシルエット**であること（冬フェーズで単体使用）
- ポリゴン数は目安。シルエットの美しさを優先してOK
