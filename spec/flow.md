# 第一幕：違和感フェーズ

“比較する癖”をプレイヤーへ植え付ける区間。

> 「でもなんか違う」

違和感を共有する。

これは超重要。

# NORMAL END

## 条件

* 一定調査達成
* TRUE条件不足

### 内容

セルフィーを警察へ持ち込む。

しかし証拠として弱い。

### 理由

* 背景ボケ
* 圧縮
* AI補正
* 主観的違和感

誰も信じない。

最後、
また少し変わった広告。

ニュース通知。

終。

---

# TRUE END

## 条件

* 高精度ログ
* Street View比較
* 同級生イベント

### 到達内容

“世界そのものが認知順応で改変されている”
と確信。

しかし代償として、
主人公自身の記憶も崩壊。

最後、
セルフィーを見返す。

背景の歯科医が、
こちらを見ている。

終。

# BAD END

主人公、
世界へ完全同化。

ニュースに映る犯人が自分でも、
違和感を抱かない。

# PARANOIA END

## 条件

* 過剰観察
* 比較依存

全てが変化して見える。

最後、
自分すら認識不能。
