# コア体験設計

## コンセプト

**「時間そのものを観測し、世界の変化を記録する認知ホラー」**

本作は「止まった世界から異変を探すゲーム」ではない。

プレイヤーは一年間の時間経過そのものを高速再生し、その中で起きる「少しずつ変化する世界」を観測・撮影・記録していく。

違和感を見つけるのではなく、「変化する瞬間」を見つけることが本作最大の体験である。

# ① 探索フェーズ（通常時間）

現在の日付は

**2019/7/7 10:00**

ここでは通常速度で時間が流れる。

プレイヤーは町を自由に歩き、

* 人に話しかける
* 建物を見る
* 商品を見る
* 景色を覚える

など、「変化前の世界」を自分の記憶へ刻む。

このフェーズでは異変は存在しない。

プレイヤー自身が「正常な世界」を記憶することが目的となる。

---

# ② チェックポイント終点へワープ

任意のタイミングで

**「チェックポイント終点（2020/7/6）へワープ」**

を選択する。

すると世界は約一年間を高速再生し始める。

プレイヤーだけが自由に歩き回れる一方、

街、人、広告、商品、建物、植物などは一年分の時間を数十倍速で進行する。

昼夜の変化

天候

季節

人の服装

商品の入れ替え

看板の変更

すべてがリアルタイムで変化していく。

---

# ③ 変化を観測する

高速再生中、

世界では様々な「シュリンク」が起こる。

例

* カントリーマアムが少し小さくなる
* コンビニの商品数が減る
* 通行人が減る
* 看板のデザインが変わる
* JKのスカート丈が変わる
* 建物が簡略化される

重要なのは、

**変化後を見ることではない。**

**変化した瞬間を見ること。**

プレイヤーは

「あ、今変わった。」

と思った瞬間にスマホで撮影を行う。

---

# ④ スマホによる記録

撮影すると、

写真はその場で縮小しながらスマホのカメラロールへ収納される。

撮影したオブジェクトは

```
AnomalyLog = true
```

として記録され、

後のリザルトやエンディング分岐の判定に利用される。

撮影する行為そのものが

「世界を書き換えられる前に証拠を保存する」

という意味を持つ。

---

# ⑤ リザルト

高速再生終了後、

プレイヤーは記録した写真を確認する。

記録された異変はログとして蓄積され、

世界改変に対する耐性となる。

逆に記録できなかった変化は

「前からこうでした。」

としてプレイヤーの認知ごと世界へ上書きされていく。

---

# 本作ならではのコア体験

一般的な異変ゲームは、

「止まった世界から違和感を探す」ゲームである。

本作では、

**時間そのものを観測する。**

世界が一年分高速で流れる中、

プレイヤーは

「変化した瞬間」

だけを見逃さないよう観察し、

その証拠をスマホへ保存していく。

つまり本作は

**「時間を観測する探偵」**

になるゲームである。

---

# プレイヤー体験

1. 普通の町を歩き、現在を記憶する。

2. 世界を一年分高速再生する。

3. 少しずつ変化する世界を観察する。

4. 変化した瞬間を撮影する。

5. 証拠を保存する。

6. 記録できなかった世界は「前からこうだった」と上書きされる。

この繰り返しによって、

プレイヤー自身が「世界の記録者」となり、

15年間にわたる世界改変の真実を追っていく。
